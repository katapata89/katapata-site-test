Sloper Tool

原型作成ツール

寸法入力から原型確認、調整、PDF出力まで進むKATAPATA本体を開きます。初めて使う場合は、先にガイドを見てから進むと流れがつかみやすいです。

Main Tool

KATAPATAを開く

現在の最新版KATAPATA本体は、この下のボタンから開ける想定です。サイト版では、ここから製図画面へ移動します。

原型作成ツールを開く はじめてガイドを見る

作業前のメモ

  • 入力単位はcmです。
  • 印刷利用前に、必ず出力後の寸法を確認してください。
  • 作業途中でガイドを見る場合は、別タブで開くと安心です。

このツールで扱う予定のもの

婦人原型

身頃・袖の原型作成、調整、ダーツ移動、確定、出力へ進む中心機能です。

ボトムス原型

スカート原型・パンツ原型など、今後の展開を含めて整理していきます。

PDF出力

縮小サンプル、標準サイズ、A4分割などの出力導線を整えていきます。
