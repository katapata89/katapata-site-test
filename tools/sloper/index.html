Sloper Tool

原型作成ツール

KATAPATA本体を開いて、サイズ入力から原型作成を始めます。初めて使う場合は、先にガイドを見ると流れがつかみやすいです。

Main Tool

KATAPATAを開く

ブラウザ上で原型を作成します。入力内容を確認しながら進め、必要に応じてPDF出力へ進んでください。

原型作成ツールを開く はじめてガイドを見る

作業前のメモ

  • 入力単位はcmです。
  • 無料出力は縮小サンプルPDFです。
  • 有料出力では、通常サイズPDFとA4分割PDFをセットで使えます。トップスは800円、ボトムスは500円を予定しています。
  • 実際に使う前に、必ず印刷後の寸法を確認してください。

扱えるもの

身頃・袖の原型

文化式婦人原型をもとに、身頃と袖の原型を作成します。

ボトムス原型

スカート原型・パンツ原型も、サイト内で整理していく予定です。

PDF出力

無料の縮小サンプルと、有料の印刷用PDFを用意します。
